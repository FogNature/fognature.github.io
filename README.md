# Портфолио Павла Гершевича

## Локальный просмотр

Выполните команду из папки сайта, где лежит `index.html`.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте [локальный сайт](http://127.0.0.1:8000/). HTTP-сервер позволяет проверить в том числе анимации, которые загружаются как JavaScript-модули.

## Обновление контента

- Основной текст, карточки блога и контакты находятся в `index.html`. Обложки статей лежат в `assets/blog/`.
- Выступления редактируются в `talks.js`. Счётчик «30+» задаётся отдельно в `index.html`.
- Порядок фотографий и подписи находятся в `event-photos.js`. Новые кадры можно добавлять в `assets/events/` вместе с вариантами `-small.webp` и `-preview.webp`.

## GitHub Pages

1. Создайте публичный репозиторий `fognature.github.io` в аккаунте `FogNature`. Если он уже существует, сначала проверьте, какой сайт из него публикуется.
2. Поместите содержимое папки сайта в корень репозитория. В корне должны лежать `index.html`, папка `assets/` и файл `.nojekyll`.
3. Отправьте файлы в ветку `main`.
4. В настройках репозитория откройте **Settings → Pages**. Выберите **Deploy from a branch**, ветку **main** и папку **/(root)**. Нажмите **Save**.
5. После успешного развёртывания откройте сайт через **Visit site**. Для репозитория `fognature.github.io` адресом будет `https://fognature.github.io/`.

После первой публикации изменения из `main` выкладываются автоматически. После подтверждения публичного адреса укажите абсолютный HTTPS-адрес изображения в `og:image` и проверьте превью ссылки в мессенджере.

[Настройка источника публикации в документации GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
